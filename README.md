# Kalos - RPG en Python

## 📌 Prérequis
Avant de commencer, assurez-vous d'avoir les éléments suivants installés sur votre machine :
- Python **3.6+**
- Pygame
- termcolor

## 🛠️ Installation
Si vous n'avez pas les modules requis, vous pouvez installer les dépendances avec **pip** en exécutant la commande suivante :
```pip install -r requirements.txt```

## 🚀 Utilisation
- Exécutez **RPG.py** dans un **IDE avec terminal intégré** comme **Visual Studio Code** ou **Thonny**.
### 🔧 Configuration selon l'IDE :
- **Visual Studio Code** : Aucune configuration requise, tout fonctionne directement !
- **Thonny** : Modifier l'interpréteur Python pour utiliser celui installé sur votre machine *(Exemple : `C:\Program Files\Python312`)* au lieu de celui de Thonny.
  ⚠️ ***Dans Thonny, le jeu fonctionne mais sans sons ni musiques !***

## 🏆 Test de la Quête
Pour tester le fonctionnement des quêtes :
- **Augmenter le niveau des monstres** (autres que Slimy).
- **Augmenter EN et EN_MAX** dans `PERSONNAGE`.
- **Utiliser le cheatcode `666`** pendant un combat pour tuer instantanément un ennemi.
